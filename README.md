# Thesis 45: Bone Density Loss Countermeasures for Long-Duration Spaceflight

**Status:** Completed
**Author:** Kelechi Emeka Ogbonna
**Affiliation:** Independent computational research / Project Confluence

## Overview
This repository contains the manuscript for Thesis #45 in the Project Confluence series. It details an ODE model of osteoclast-osteoblast dynamics under microgravity conditions, examining the structural identifiability of countermeasure forcing terms from DXA-like bone mineral density observations during Mars-transit schedules.

This work builds upon the computational identifiability methods developed in Thesis T07 (identifiability methods), T09 (multi-channel identifiability), and T12 (stiff-sloppy reduction), expanding the physiological and mathematical focus beyond the foundational principles established in Thesis Zero.
